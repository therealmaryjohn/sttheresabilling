# ST. THERESA Billing

## Update steps
1. Open `js/config.js` from this zip and paste your **googleClientId** back in. The file in this zip has it empty.
2. Upload **all** files to GitHub, replacing the old ones.
3. Open the site and tap **⟳ Sync**.

## What's included
- **All old bills DC/0001 – DC/0024** (2026-27). Their totals match the original PDFs. New bills continue from **DC/0025/26-27**.
- **9 customers** from those bills, plus the product catalogue P001–P060 and other products.
- **E-way bills already linked:** DC/0003 (5020 6555 4428), DC/0010 (5120 8813 9333), DC/0013 (5720 8964 0353).
- **DC/0020 (₹1,00,548)** shows **E-Way Bill missing**.

## E-way bills
- **📎 Attach EWB** opens a form for the e-way bill number, date, vehicle and PDF. The PDF is saved to `E-Way Bills/26-27/EWB_DC_00xx_26-27.pdf`.
- **📄 E-Way Bill** opens the attached PDF.
- In **Bills**, the dropdown can show *E-Way Bill missing* or *Has E-Way Bill*.

## Old invoice PDFs
Tap **📎 Attach PDF** on each old bill. The site can only open files it uploaded itself.
